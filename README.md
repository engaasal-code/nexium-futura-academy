# NEXIUM FUTURA ACADEMY

منصة تعليمية أونلاين لكل المراحل الدراسية (KG – ابتدائي – إعدادي – ثانوي) + كورسات الصيف.
ثلاث بوابات: **الطالب / ولي الأمر** – **المدرس** – **الإدارة**، بالعربي والإنجليزي، ومتوافقة مع الموبايل والتابلت والكمبيوتر.

المنصة بتشتغل بطريقتين:
- **نسخة تجريبية** (الوضع الافتراضي): بيانات وهمية محفوظة في متصفح كل شخص – مناسبة للعرض والتجربة.
- **نسخة حقيقية**: متوصلة بـ **Supabase** (قاعدة بيانات + حسابات + رفع ملفات + إيميلات) – **اتبع الخطوات في [SETUP.md](SETUP.md)**.
  التحويل بيتم بإنك تحط رابط مشروعك ومفتاحه في `js/config.js` بس.

## الروابط
| البوابة | الرابط |
|---|---|
| الطالب / ولي الأمر | `index.html` |
| المدرس | `index.html#teacher` |
| الإدارة | `index.html#admin` |
| صفحة تعريفية | `index.html#page-terms` (أو about / faq / refund / privacy) |

حسابات التجربة: من أزرار "دخول سريع" في صفحة الدخول – كلمة المرور لكل الحسابات `123456`.

## هيكل الملفات – تعدّل إيه فين؟
| الملف | فيه إيه |
|---|---|
| `index.html` | الصفحة الرئيسية اللي بتحمّل كل الملفات (نادراً ما تحتاج تعدّلها) |
| `css/style.css` | الألوان والخطوط والتصميم ومقاسات الموبايل والتابلت. الألوان الأساسية في أول الملف (`--navy` و `--gold`) |
| `js/config.js` | مسارات اللوجو + **ربط Supabase** (لو فاضي = نسخة تجريبية) |
| `js/core.js` | **البيانات**: المراحل والمواد، الأسعار والباقات، الدول والعملات، الصلاحيات، المدرسين والطلاب التجريبيين، الصفحات التعريفية، روابط السوشيال، وفلتر منع أرقام التليفون في الشات |
| `js/ui.js` | الهيدر، القائمة الجانبية، الفوتر، صفحة الدخول والتسجيل، الصفحات التعريفية، الأيقونات |
| `js/student.js` | كل صفحات الطالب وولي الأمر (الحجز، المواد والأسعار، حصصي، التقرير، الشات، المدفوعات، الإعدادات) |
| `js/teacher.js` | كل صفحات المدرس (الحصص والحضور، المواعيد، الطلاب، الواجبات، التقييم، المستحقات) |
| `js/admin.js` | كل صفحات الإدارة (الداشبورد المالي، صافي الربح، المدفوعات، المدرسين، الصلاحيات، الصفحات، السوشيال…) |
| `js/home.js` | **واجهة الموقع** للزوار + محرّر الواجهة في لوحة الإدارة (كل النصوص والصور بتتعدل من الإدارة ← واجهة الموقع) |
| `js/annotate.js` | **تصحيح الواجب على الورقة**: قلم، هايلايتر، دواير، ✓ ✗، كتابة، ختم الدرجة – على الصور وملفات PDF |
| `js/savebar.js` | شريط **"حفظ التغييرات"** في لوحة الإدارة (التعديلات مش بتظهر على الموقع غير بعد الحفظ – Ctrl+S للحفظ السريع) |
| `js/stats.js` | **عدّاد الزيارات** و**ملخص الشهر** في نظرة عامة (الزيارات، المبيعات، الطلبات، هدف الشهر) |
| `js/images.js` | **مقاسات الصور**: كل صورة ليها مقاس ثابت وأقل مقاس مقبول وأقصى حجم، وشاشة قص قبل الرفع. المقاسات في `IMG_SPECS` أول الملف |
| `js/security.js` | حماية الواجهة: تنظيف الروابط ومحتوى الصفحات، وقواعد كلمة المرور |
| `js/vendor/` | مكتبات ثابتة جوه المشروع (Supabase و PDF.js) بدل تحميلها من الإنترنت |
| `js/backend.js` | الربط بالسيرفر في النسخة الحقيقية: الدخول والتسجيل، تحميل وحفظ البيانات، الحجز والدفع ورفع الملفات |
| `js/main.js` | تشغيل المنصة |
| `supabase/schema.sql` | قاعدة البيانات وقواعد الأمان والصلاحيات وإيميلات التذكير (بيتشغّل مرة واحدة في Supabase) |
| `supabase/NEXIUM_DB_UPDATE_v4.sql` | **تحديث v4**: المدرسين بيفعّلوا بالإيميل بس، الكود للإدارة بس، رئيس تنفيذي جديد، عدّاد الزيارات |
| `supabase/update_v2.sql` | **تحديث v2** لقاعدة بيانات شغالة بالفعل (الأمان + الواجهة + التصحيح + الصور + التقييم المبدئي) |
| `supabase/owner_emergency.sql` | طوارئ لحساب صاحب المنصة (كلمة مرور جديدة / موبايل ضاع) |
| `supabase/seed.sql` | البيانات الأساسية: المراحل والمواد والأسعار والصفحات والإعدادات |
| `SETUP.md` | دليل تشغيل النسخة الحقيقية خطوة بخطوة |
| `assets/` | اللوجو |

### أمثلة تعديلات سريعة
- **تغيير رقم الواتساب أو السوشيال الافتراضي:** في `js/core.js` دوّر على `social:` (أو من لوحة الإدارة ← السوشيال والتواصل).
- **إضافة / حذف مادة:** في `js/core.js` – القائمتين `SUBJ_LIB` و `STAGE_SUBJ`.
- **تغيير سعر الحصة الأساسي لكل مرحلة:** في `js/core.js` – `BASE_PPS`.
- **تغيير الباقات (عدد الحصص والخصم):** في `js/core.js` – `PACKAGES`.
- **تغيير الألوان:** في أول `css/style.css`.
- **تبديل اللوجو:** استبدل الصور في `assets/` بنفس الاسم.

> 💡 في **النسخة التجريبية**: بعد أي تعديل في `js/core.js` افتح لوحة الإدارة واضغط **"إعادة البيانات التجريبية"**.
> في **النسخة الحقيقية**: المواد والأسعار والصفحات والسوشيال بتتعدل من لوحة الإدارة مباشرة (مش من الملفات).

## تشغيلها أونلاين مجاناً (GitHub Pages)
1. ارفع الملفات على الـ repository.
2. **Settings ← Pages ← Build and deployment**: اختار **Deploy from a branch**، والفرع `main` والمجلد `/ (root)` ← **Save**.
3. بعد دقيقة أو اتنين هيظهر لينك زي: `https://USERNAME.github.io/nexium-futura-academy/`
4. أي تعديل تعمله وتحفظه (Commit) بيظهر على اللينك تلقائياً خلال دقيقة.

## تشغيلها على جهازك
افتح `index.html` في المتصفح مباشرة، أو من التيرمنال داخل المجلد:
```
python -m http.server 8000
```
وافتح `http://localhost:8000`
